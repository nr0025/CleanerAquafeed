# 方法与实现

[English](methods.md)

公式编号与论文一致。原料添加量 *x*ᵢ 的单位为 kg/t 全价饲料；固定 20 kg/t 的预混料补足一吨，不计营养、干物质、能量、成本和环境影响。营养限值均为原样基础的总养分。所有配方（包括参考配方）还须满足植物性粕类总量的上限。

## 结果层级

* 原料层：每 kg 原样原料在出厂时的生命周期系数（数据库列 `gwp` … `wu`）。
* 配方层：1 kg 原样饲料中原料的上游影响（`candidates_evaluation.csv` 中的 `*_ratio`、`*_change_pct`）。
* 预测生产层：配方层影响乘以预测 FCR，即每 kg 预测增重的影响（`growth_summary.csv` 中的 `*_per_gain_*`）。

## 1. 线性配方模型 — `formulation.py`

| 内容 | 公式 | 实现 |
|---|---|---|
| 质量平衡 | Σ*x*ᵢ + *x*ₚₘ = 1000 | `base_model` |
| 营养限值（表 1） | *N*ₙᵐⁱⁿ ≤ Σ*a*ᵢₙ*x*ᵢ/1000 ≤ *N*ₙᵐᵃˣ | `base_model`，限值见 `[nutrients]` |
| 赖氨酸/粗蛋白比 | Σ*a*ᵢ,Lys*x*ᵢ ≥ ρ Σ*a*ᵢ,CP*x*ᵢ（线性形式，式 4） | `base_model` |
| 植物性粕类总量 | Σ_{*i* ∈ 植物性} *x*ᵢ ≤ 450 kg/t（植物来源原料，不含油脂） | `base_model`，限值 `plant_max`，`origin = plant` 的原料 |
| 添加上下限 | *LB*ᵢ ≤ *x*ᵢ ≤ *UB*ᵢ | 数据库 `lb_kg_t`、`ub_kg_t` 列 |
| 干物质 | (Σ DMᵢ*x*ᵢ + DMₚₘ*x*ₚₘ)/1000 ≥ 89% | 预混料干物质由 `premix_dm` 设定（默认 0） |
| 参考配方 | 固定 *x*_FM，最小化 Σ*P*ᵢ*x*ᵢ（式 1–6） | `reference_diets`；使用完整原料库 |
| 候选配方 | 式 2–5，300 ≤ *x*_FM ≤ 450，GE ≥ max(12.5, 0.97 GE_FM45)（式 7–9） | `candidate_model` |

所有问题都通过 `scipy.optimize.linprog` 调用 HiGHS 求解。约束和目标都是线性的，因此每次求解都返回可行多面体的一个顶点，且为全局最优。

### 候选配方生成（式 10–12）

* 归一化系数：*p*ᵢ = *P*ᵢ / *C*_FM45，*e*ᵢₖ = *E*ᵢₖ / Σⱼ *x*ⱼ,FM45 *E*ⱼₖ，使 Σ*x*ᵢ*p*ᵢ = *C*ᵣ、Σ*x*ᵢ*e*ᵢₖ = *R*ₖ（`normalised_coefficients`）。
* 指定目标：基准价格和最高价格下的最低成本、六项指标各自最小，以及折中目标 0.5 *C*ᵣ + 0.5 *E*ₘ。
* 2,000 个随机目标：成本权重 *w*₀ ~ U(0, 1)，其余 1 − *w*₀ 按均匀 Dirichlet 分布分给六项指标。
* 打破并列最优的扰动：εᵢ = 10⁻⁴ · mean|*c*| · *u*ᵢ，*u*ᵢ ~ U(0, 1)。
* 相差不超过 10⁻⁴ kg/t 的顶点视为同一个。
* 凸组合：抽取 1,000 次；每次随机取 *k* ~ U{2, …, 5} 个不同顶点，权重 λ ~ Dirichlet(1, …, 1)。每个候选配方在保留前都检验全部约束。

候选集覆盖的是已找到顶点的凸包，而不是整个可行多面体；各类别所占比例取决于抽样设计。

## 2. 评价与分类 — `evaluation.py`

* *C*ᵣ = *C*_f / *C*_FM45（式 15），*R*ₖ = *I*_f,k / *I*_FM45,k（式 16），*E*ₘ 为六项 *R*ₖ 的平均值（式 17）。
* 负担转移惩罚 *B* = Σ max(0, *R*ₖ − 1.10)（式 18）；评分 *S* = 0.5 *C*ᵣ + 0.5 *E*ₘ + 2 *B*（式 19）。
* 规则：R1 *C*ᵣ ≤ 1.10；R2 *R*_GWP < 1；R3 至少四项 *R*ₖ < 1；R4 *B* = 0。稳健候选按式 (20) 排序。
* 其余类别按以下顺序判定：超出成本容差（不满足 R1）；降低 GWP 但有负担转移（满足 R2 且 *B* > 0）；未降低 GWP 的部分改善（*R*_GWP ≥ 1 且 *E*ₘ < 1）；其余为在成本容差内但环境收益有限。
* 成本不含预混料，因为各配方的预混料相同。

## 3. 不确定性 — `uncertainty.py`

* 价格：在最低价与最高价之间均匀抽样；独立抽样 2,000 次，或通过高斯 copula 施加一个公共因子（潜变量两两相关系数 ρ = 0.3、0.6、0.9，各 2,000 次）。候选配方与基准配方使用同一组抽样价格；*P*_risk 为 *C*ᵣ > 1.10 的样本比例（式 22）。
* LCA 系数：每个 *E*ᵢₖ 乘以 U(0.7, 1.3) 或 U(0.5, 1.5) 的因子，可独立抽取，也可每种原料一个因子、六项指标共用（各 2,000 次）；*P*_robust 为满足 R1–R4 的样本比例，成本取确定值。
* 阈值：成本容差 0–20%、最少降低指标数 3–6、负担转移容差 0–20%（共 80 种组合），以及去掉 R2。

## 4. 对照优化 — `benchmarks.py`

* 直接线性规划：在候选约束和 R1、R2、R4 下最小化式 (20)（R3 事后检验）。
* 等能量线性规划：在上述基础上令 Σ*x*ᵢ EAᵢ 等于 FM45。由于配方只通过 *E*_A 影响生长模型，这一约束使预测生长与基准相同。
* 改编自 Garcia-Launay 等（2018，Br. J. Nutr. 120, 1298–1309）的加权和配方：在候选约束下最小化 (1 − α) *C*ᵣ + α *E*ₘ，所有 *R*ₖ ≤ 1.05，粗蛋白不高于 FM45，α = 0, 0.01, …, 1。按原文取 α_lim，即此后环境指数的边际下降小于成本指数边际上升的那一点。与原方法的差异：以 FM45 代替最低成本配方作参照；以等权的六项 ReCiPe 指标代替原文四项影响的加权指数。两项指数都以 FM45 归一化时，式 (20) 就是 α = 0.5 时的目标函数。
* 添加上限敏感性：改变禽类蛋白、肉骨粉和鱼粉的上下限，以及去掉两种动物副产品蛋白后，重新求解直接线性规划。另将植物性粕类总量上限设为 45%（基准）、50% 和不设上限，重新求解最低成本 FM35 配方，并与基准情景的 FM45 比较（表 S9d）。

## 5. 生长模型 — `growth.py`

* *E*_A = Σ*x*ᵢ (23.6 CPᵢ ADC_N,ᵢ + 39.5 Lᵢ ADC_L,ᵢ)/1000，MJ/kg（式 23）。ADC_N 为 INRAE-CIRAD-AFZ 饲料营养价值表中鲑鳟鱼的氮消化率，ADC_L 为同一表中鲑鳟鱼的能量消化率；与大口黑鲈实测值的对比见表 S11。
* 摄食量 *C* = min(0.065 *W*⁰·⁷⁵ τ(*T*), 0.03 *W*) g/d，原样基础（式 24）；τ(*T*) 为 Kitchell 型函数，*T*_max = 37 °C，*T*_opt = 27.5 °C，*Q*₁₀ = 2.65。
* d*W*/d*t* = ((1 − 0.20 − 0.15) *C* *E*_A − *R*_A) / *E*_f，*E*_f = 5.01 *W*⁰·⁰⁴⁶ kJ/g（式 25）；呼吸 *R*_A = 13.56 · 0.3393 *W*^−0.3486 e^0.028T e^0.0196·5 *W* · 0.024 kJ/d。
* 28 °C 下从 10 g 养殖 70 天；2,000 尾鱼只用于折算饲料成本。用 RK45 积分（相对误差 10⁻⁸）。
* 摄食、呼吸和能量密度都与配方无关，因此末重随 *E*_A 单调增加（见 `tests/`）。
* 表 S10 还给出每个模拟配方的：每 kg 预测增重的环境影响（相对 FM45，= 每 kg 饲料影响比 × FCR/FCR_FM45）；可消化粗蛋白 Σ*x*ᵢ CPᵢ ADC_N,ᵢ（分别用数据库 ADC 和大口黑鲈平均 ADC-N）；以及肉骨粉和禽类蛋白提供的粗蛋白比例。

## 6. 原料贡献分解 — `attribution.py`

* 成本和六项环境影响对原料添加量都是线性的，因此各比值相对 FM45 的变化可以精确拆成每种原料一项（式 26）：*R*ₖ − 1 = Σᵢ (*x*ᵢ − *x*ᵢ,FM45) *E*ᵢ,ₖ / (1000 *I*_FM45,k)，*C*ᵣ − 1 = Σᵢ (*x*ᵢ − *x*ᵢ,FM45) *P*ᵢ / *C*_FM45。对 *E*ₘ 的贡献取六项指标贡献的平均值。
* `contributions()` 返回"配方 × 原料 ×（成本、六项影响）"的数组；`check_exact()` 检查各项之和与 `evaluate()` 的结果一致（`tests/` 中也有检查）。
* 不拟合任何模型，因此不需要验证，原料之间的共线性也不影响结果。
* 规则不满足的归因：R1 归到成本，R2 归到 GWP，R3 归到每个 *R*ₖ ≥ 1 的指标，R4 归到每个 *R*ₖ > 1.10 的指标；再分别归到对该指标正贡献最大的原料。
* 输出：`attribution_diets.csv`（FM35、FM55、前 20 名及其平均；表 4、表 S6），`attribution_rule_counts.csv` 和 `attribution_rule_failures.csv`（表 S7a–b），`attribution_composition_by_class.csv`（表 S7c），`attribution_candidates.csv`（表 S8）。
